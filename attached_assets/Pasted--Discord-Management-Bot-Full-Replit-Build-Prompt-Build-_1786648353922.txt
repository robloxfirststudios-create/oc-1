The bot is intended for Roblox/ER:LC-style communities and staff teams.

## MOST IMPORTANT REQUIREMENT — SAVE REPLIT CREDITS

You MUST prioritize using the **least possible Replit/AI credits**.

Before doing anything:

* Inspect the existing project.
* Do NOT unnecessarily recreate files that already work.
* Do NOT repeatedly rewrite the same code.
* Do NOT install unnecessary packages.
* Use lightweight, reliable dependencies.
* Avoid external APIs unless absolutely necessary.
* Prefer Discord's native features.
* Use SQLite or another lightweight local database rather than a large database service.
* Keep configuration centralized.
* Build reusable components instead of duplicating code.
* Fix only the relevant files when debugging.
* Do not generate huge amounts of unnecessary documentation.
* Do not use AI APIs inside the Discord bot.
* Do not create unnecessary animations or resource-heavy systems.
* Keep the bot capable of running cheaply on Replit.
* After completing a feature, test it before moving onto the next feature.
* Do not rebuild working features unless required.

The finished bot should be efficient enough to run on a small/cheap Replit deployment.
